Integrasi Google Sheets Cloud

Data hanya disimpan di memori browser lokal perangkat ini.

Buka Google Sheets

Dihasilkan dari Apps Script: Terapkan (Deploy) > Aplikasi Web (Akses: Siapa saja).

Tautan langsung agar Anda bisa membuka spreadsheet dengan satu kali klik.

Kirim data ke Google Sheets saat menyimpan presensi, tambah siswa, kelas, dll.

Cara Memasang Backend Google Apps Script

Google Apps Script berfungsi sebagai backend gratis & resmi untuk menghubungkan antarmuka ini langsung dengan Google Spreadsheet Anda.

1

Buat Spreadsheet Baru

Buka sheets.google.com dan buat spreadsheet kosong baru dengan nama SIM-Guru Bahasa Indonesia.

2

Buka Menu Apps Script

Pada menu atas spreadsheet, klik Ekstensi (Extensions) > Apps Script.

3

Salin & Tempel Kode Skrip

Hapus seluruh isi editor bawaan, lalu paste (tempel) kode skrip di bawah ini, lalu simpan (Ctrl+S).

4

Terapkan Sebagai Aplikasi Web (Deploy as Web App)

Klik tombol Terapkan (Deploy) > Kelola Penyiapan (New deployment) > Pilih jenis Aplikasi Web.
• Jalankan sebagai: Saya (email Anda)
• Siapa yang memiliki akses: Siapa saja (Anyone) *(Wajib dipilih!)*
• Klik Terapkan, dan berikan izin akses akun jika diminta.

5

Hubungkan ke Aplikasi Web Ini

Salin URL Aplikasi Web berakhiran /exec, buka kembali tab Konfigurasi di modal ini, tempelkan, lalu klik Simpan & Terapkan.
